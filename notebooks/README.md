# AITH DL Competition – табличные решения

- `tabular_nn_pipeline.ipynb`: основной ноутбук с комментариями на русском, анти-лик гарантиями, CV, базовым MLP и экспериментами (усиленный MLP и FT-Transformer). Здесь самые свежие правки.
- `tabular_nn_pipeline.py`: быстрый скриптовый вариант без ноутбучных объяснений; воспроизводит базовый MLP-пайплайн и генерирует submission.

Данные ищутся относительно корня репозитория (`data/competition`). Сабмишены пишутся в `results/` с таймстемпом (MSK). Запускать с установленными зависимостями (torch, pandas, numpy, scikit-learn); для стабильности можно ставить `OMP_NUM_THREADS=1 MKL_NUM_THREADS=1`.
